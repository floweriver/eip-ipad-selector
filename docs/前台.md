# 前台選機頁（Front）

> v1.0.0 | 2026-07-20 | 初版：一頁式下滑選機 + 常駐比價，Apple 官網風格，待驗收

## 功能說明

客人用的一頁式網頁（`/`），由上往下三步驟，每步自動平滑捲動：

1. **選系列**：四張系列卡（圖取自 ipad_series.image_url）；旁邊附「不知道型號？」A 碼查詢（即時比對，查到直接跳結果）。
2. **選型號**：該系列的型號膠囊按鈕（只列 is_active = true，照後台排序）。
3. **結果**：
   - 「整套買齊，最多省 NT$Y」黑色大卡：每分類 eiP 最低價 vs Apple 原廠最低價，正差額才列出並加總；該分類無原廠對照則自動跳過。
   - 分類頁籤（只顯示有相容產品的分類）→ 產品卡片：圖、名稱、價格、推薦徽章（ranking 有值者排前、再依價格）、「前往購買」（website_link → original_link → shopee_link 依序遞補）。

## 架構

- `app/page.tsx`（Server Component）：一次撈全部前台資料（8 張表查詢、`force-dynamic` 每次最新），傳給 client。
- `app/home-client.tsx`（Client Component）：所有互動（選擇、捲動、A 碼查詢、比價計算）都在瀏覽器端做，選擇零延遲、不再打資料庫。
- 資料量小（30 型號 / 43 產品 / 298+58 關聯 / 102 A 碼），一次載入約幾十 KB，可行。
- 視覺：Apple 官網風——#f5f5f7 淺灰底、白圓角卡、#0071e3 藍、膠囊按鈕、大標粗體。

### 重要決策記錄

| 決策 | 原因 | 排除的方案 |
|------|------|-----------|
| 一頁式下滑（非多頁） | Fred 指定：讓消費者盡快得到結果 | 三頁式路由（可分享單頁連結，但多次跳轉） |
| 全部資料一次載入、互動純前端 | 資料量小；選擇零等待 | 每步打 API（多次等待） |
| 讀取用 server 端連線（同後台） | 不必新增 anon key 設定；client 只拿到已查好的資料 | 前端 anon key 直連 |
| 購買連結遞補順序 lihi → 官網 → 蝦皮 | lihi 可追蹤成效；HyperKeys 無 lihi 自動用官網 | 只用單一欄位 |
| 比價只列正差額分類 | 「省多少」是賣點，負差額/無對照不干擾 | 全列（含不利資訊） |

### 已知地雷 ⚠️

- 比價依賴 apple_products 覆蓋度：舊機型還沒補原廠品項，比價卡會較少列或不顯示 → 後台陸續補。
- 產品/系列圖用外站連結（shopline / eipstore.online），對方換圖或擋外連會破圖。
- `page.tsx` 是 force-dynamic：後台改資料前台即時反映；未來流量大可再加快取。
- 型號按鈕直接顯示 model_name，改名會即時影響前台顯示。
